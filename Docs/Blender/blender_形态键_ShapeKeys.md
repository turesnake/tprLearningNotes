


在 Blender 中使用形态键（Shape Keys）让单个顶点从位置 A 移动到位置 B，其核心原理是记录物体顶点的**两个状态**（基准态和目标态），然后通过权重滑块在两者之间进行插值。

下面是详细的操作步骤和技术要点：

### 第一步：准备物体与基准形态（Basis）
1.  **创建物体**：在 3D 视图中添加一个物体（例如一个 Cube）。
2.  **进入形态键面板**：在右侧属性栏中，点击 **数据（Data）** 图标（绿色倒三角形）。
3.  **添加 Basis**：找到 **形态键（Shape Keys）** 列表，点击右侧的 **“+”** 号。
    *   第一个产生的键会自动命名为 `Basis`。
    *   **注意**：`Basis` 代表物体的原始形状，不要在选中它时修改顶点位置。

### 第二步：创建目标形态（Key 1）
1.  **添加新键**：再次点击 **“+”** 号，生成名为 `Key 1` 的新形态键。
2.  **进入编辑模式**：选中 `Key 1`，按 `Tab` 进入 **编辑模式（Edit Mode）**。
3.  **移动顶点**：
    *   选中你想要移动的那个**顶点**。
    *   按 `G` 将其从 A 点移动到 B 点。
4.  **返回物体模式**：按 `Tab` 回到 **物体模式（Object Mode）**。你会发现顶点回到了 A 点，这是正常的。

### 第三步：制作动画（插值）
1.  **调节权重**：在 `Key 1` 下方有一个 **数值（Value）** 滑块（范围 0.0 到 1.0）。
    *   当 Value 为 0 时，顶点在 A。
    *   当 Value 为 1 时，顶点在 B。
2.  **打关键帧**：
    *   将时间轴拖到第 1 帧，将 Value 设为 `0`，在滑块上按右键选择 **“插入关键帧”**（或按快捷键 `I`）。
    *   将时间轴拖到第 60 帧，将 Value 设为 `1`，再次插入关键帧。
3.  **播放**：按 `Space` 播放，你会看到该顶点沿直线从 A 运动到了 B。

---

### 技术进阶与注意事项

#### 1. 运动路径是线性的
形态键的原理是**线性插值（LERP）**。这意味着顶点会沿着 A 到 B 的最短直线运动。如果你希望顶点走弧线，通常需要：
*   增加中间形态键（Key 2, Key 3...）。
*   或者改用 **骨骼（Armature）** 配合权重来控制。

#### 2. 相对与绝对形态键
*   **相对（Relative，默认开启）**：`Key 1` 记录的是相对于 `Basis` 的“偏移量”。这是最常用的，适合表情动画。
*   **绝对（Absolute）**：如果你关闭“相对”勾选框，Blender 会根据列表顺序在各个 Key 之间按顺序过渡，这适合做生长动画或固定的变形序列。

#### 3. 混合多个形态键
你可以创建多个形态键（比如 Key 1 移动顶点 X，Key 2 移动顶点 Y）。在物体模式下，你可以同时调大两者的 Value，顶点会叠加这两个位移。

#### 4. 范围限制
如果你想让顶点移动得比 B 点更远，可以修改滑块下方的 **范围最小/最大（Range Min/Max）**。例如将 Max 设为 2.0，顶点就会沿着 AB 方向飞出两倍的距离。

### 总结
对于“只移动一个顶点”，形态键是最轻量的方法。如果你在操作中发现移动 `Key 1` 时 `Basis` 也跟着变了，那通常是因为你**在编辑模式下选错了形态键层**。始终确保在移动顶点前，列表里高亮选中对应的那层 `Key`。



# =========================================== #
#     如何在 unity 中直接使用形态键
# =========================================== #

这是一个非常好的问题。简单直接的回答是：**Unity 可以直接使用 Blender 制作的形态键数据。**

在 Unity 中，Blender 的“形态键 (Shape Keys)”会被自动识别并更名为 **“混合形状 (BlendShapes)”**。

你不需要非得在 Blender 里做成动画文件（Action），你可以直接在 Unity 引擎里通过代码、插件或者 Unity 的时间轴（Timeline）来实时控制这些顶点的位移。

以下是详细的技术实现细节：

### 1. 如何将形态键导入 Unity
1.  **导出格式**：在 Blender 中导出为 `.fbx` 格式。
2.  **导出设置**：在导出面板的 `Mesh` 选项中，确保勾选了 **Apply Modifiers**（但注意：某些修改器如 *Subdivision Surface* 可能会导致形态键失效，通常建议先应用除形态键以外的修改器）。
3.  **Unity 导入设置**：将 FBX 拖入 Unity 后，在 Inspector 面板的 `Model` 选项卡下，确保勾选了 **Import BlendShapes**。

### 2. 在 Unity 中查看和测试
1.  将模型拖入层级（Hierarchy）。
2.  找到带有 **Skinned Mesh Renderer** 组件的子物体。
3.  展开 **BlendShapes** 栏目，你会看到你在 Blender 里命名的 `Key 1`。
4.  拖动旁边的数值（0-100，注意 Unity 的范围是 0-100，而 Blender 是 0-1），你会发现顶点实时在移动。

### 3. Unity 中控制形态键的两种方案

#### 方案 A：直接在 Unity 中制作动画（推荐）
你不需要在 Blender 里打关键帧。
*   打开 Unity 的 **Animation** 窗口。
*   录制关键帧，直接修改 `Skinned Mesh Renderer` 下的 `BlendShape.Key 1` 属性。
*   这种方式的优点是：你可以在 Unity 里精确控制动画逻辑，方便与游戏事件同步。

#### 方案 B：通过代码动态控制（最强大）
如果你想根据游戏逻辑（比如角色挨打脸部变形、或者根据 UI 滑块控制捏脸），可以使用代码：

```csharp
using UnityEngine;

public class ShapeKeyController : MonoBehaviour
{
    SkinnedMeshRenderer skinnedMeshRenderer;

    void Start()
    {
        skinnedMeshRenderer = GetComponent<SkinnedMeshRenderer>();
    }

    void Update()
    {
        // 实时将第一个形态键（索引为0）设置为 50% 的变形程度
        float val = Mathf.PingPong(Time.time * 100, 100); 
        skinnedMeshRenderer.SetBlendShapeWeight(0, val);
    }
}
```

### 4. 关键技术限制（避坑指南）
虽然 Unity 支持形态键，但有几个点必须注意：

*   **顶点数量必须一致**：你不能在形态键中增加或删除顶点，只能移动位置。
*   **计算开销**：形态键是在 GPU 上进行的顶点偏移计算。如果一个精细模型有几百个形态键同时开启，会对性能产生影响（尤其在移动端）。
*   **法线问题**：如果变形非常剧烈，Unity 的光影可能会看起来很奇怪。在导出 FBX 时，建议设置 `Smoothing` 为 `Face` 或在 Unity 导入设置中调校 `Normals` 选项。
*   **名称匹配**：如果你在 Blender 里把形态键删了重建，记得检查 Unity 里的动画引用，因为 Unity 是靠字符串名称或索引来寻找这些形状的。

**总结建议：**
如果你只是想实现“顶点从 A 到 B”的简单动画，**建议在 Blender 里只创建形态键，不要打关键帧**。把模型导入 Unity 后，利用 Unity 的 **Timeline** 或 **Animation** 窗口来做动画，这样后期调整速度和触发逻辑会方便得多。

#     形态键 动画 制作
# =========================================== #
前提确认
绝对模式下，每个形态键有一个 Value（时间值），Blender 会根据 Evaluation Time 在各键之间插值：
    base → Value = 0
    10 → Value = 10
    20 → Value = 20

操作步骤
第一步：确认帧率
    右侧 properties - Scene(打印机图标), 头部的 formart - frame rate: 设为 30;


第二步：设置时间线范围
    在时间线编辑器底部，将 Start 设为 0，End 设为 29。

第三步：在第 1 帧插入关键帧
    在时间线将当前帧移动到第 1 帧。
    选中你的 Mesh 对象，进入 Properties → Object Data Properties（绿色三角形图标）→ Shape Keys。
    找到 Evaluation Time 字段（在形态键列表下方）。
    将 Evaluation Time 的值设为 0（对应 base 键）。
    鼠标悬停在 Evaluation Time 输入框上，右键单击，选择 Insert Keyframe。

第四步：在第 25 帧插入关键帧
    在时间线将当前帧移动到第 25 帧。
    将 Evaluation Time 的值设为 20（对应形态键 20）。
    鼠标悬停在 Evaluation Time 输入框上，右键单击，选择 Insert Keyframe。

第五步：确认插值为线性 (也可不改)
    默认关键帧插值是 Bezier，需要改为 Linear：
    打开 Graph Editor（图形编辑器）。
    找到 Evaluation Time 的曲线（Key → Evaluation Time）。
    选中所有关键帧点（点击一个，再点击另一个，或框选）。
    在顶部菜单点击 Key → Interpolation Mode → Linear。

第六步：播放预览
    回到时间线，点击播放按钮，即可看到 Mesh 在 1 秒内从 base(0) 线性过渡到 20 的动画。
