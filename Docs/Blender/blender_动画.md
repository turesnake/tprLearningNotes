#               循环动画  变得连贯
# ---------------------------------------------- #

当制作了一段循环动画, 播放的时候会发现首位不流畅

这是因为首位帧 丢失了自己的 某一侧的曲线信息, 

# -- 方案1:
    手动在首尾外侧, 补上两个帧, 手动补上信息
    ---
    虽然笨, 但推荐


# -- 方案1:
    进入 graph editor, 先选中一个曲线, 然后 select - all, 此时会全选曲线,
    然后看到窗口右侧有个 modifies, 进去添加一个 curve 修改器
    会发现所有曲线都有首位信息了
    ----
    这个方案的缺陷是, 整个 anim clip 只能做这一个动画了
