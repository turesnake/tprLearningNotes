


在工商经营里，**ICP** 通常指 **互联网信息服务备案/许可证**，全称是 **Internet Content Provider**，中文常说“ICP备案”或“ICP许可证”。

简单区分：

1. **ICP备案**
   - 适用于：网站、APP、小程序等提供互联网信息服务，但**不直接收费经营**的情况。
   - 常见例子：公司官网、展示型网站、品牌宣传页。
   - 一般由网站服务器接入商协助在工信部系统备案。
   - 备案号格式类似：`粤ICP备xxxxxxx号`

2. **ICP许可证**
   - 适用于：通过互联网提供**经营性信息服务**，也就是有盈利性质的平台服务。
   - 常见例子：电商平台、会员付费网站、信息发布收费平台、在线交易撮合平台等。
   - 属于增值电信业务经营许可证的一种，通常是 **B25 信息服务业务**。
   - 不是所有公司都能直接办，通常对注册资本、人员、社保、网站/系统等有要求。

一句话理解：

**普通公司官网一般做ICP备案；如果你通过网站/平台收费经营互联网信息服务，可能需要ICP许可证。**

如果你是在营业执照经营范围里看到“ICP”，多半和“互联网信息服务”“第二类增值电信业务”有关。



但只有一个股东的公司股东的法律风险太大了。
